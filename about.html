О проекте

🎮 Что это?

Это полноценная реализация классического Тетриса на чистом HTML, CSS и JavaScript. Проект создан в рамках лабораторной работы.

🛠️ Технологии

  • HTML5 — структура страниц
  • CSS3 — стилизация и анимации
  • JavaScript — логика игры
  • Canvas API — отрисовка игрового поля
  • GitHub Actions — автоматический деплой
  • localStorage — хранение рекордов

✨ Особенности

  • 7 классических фигур (тетрамино)
  • Система уровней и очков
  • Таблица рекордов
  • Пауза и мгновенное падение
  • Отображение следующей фигуры
  • Адаптивный дизайн

👥 Команда

Проект разработан командой из 4 человек:

  • Лидер — координация и документация
  • DevOps — CI/CD и инфраструктура
  • Программист 1 — HTML и CSS
  • Программист 2 — JavaScript
